# ghostplatform.ai

The marketing website for G.H.O.S.T., built and supported by Cypher, LLC. Plain HTML, CSS and a little JavaScript: no build step, nothing to install. Open `index.html` in a browser, or publish the folder with GitHub Pages.

## Documents

The G.H.O.S.T. PDFs are kept in this repository only, on the [`documents` branch](https://github.com/janderson715/Ghost-site/tree/documents). They are not part of the website and nothing on the site links to them.
