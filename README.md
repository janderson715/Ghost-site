# ghostplatform.ai

The marketing website for G.H.O.S.T., built and supported by Cypher, LLC. Plain HTML, CSS and a little JavaScript: no build step, nothing to install. Open `index.html` in a browser, or publish the folder with GitHub Pages.

## PDF documents (for downloading, not shown on the site)

`documents/` holds the latest G.H.O.S.T. handbook, brochures, extended capabilities and agent cards as PDFs, each in a dark (screen) and a white (print) version. Nothing on the website links to them; they are here so you can download the newest copy. When Ray rebuilds them, the files are replaced, so run `git pull` and take the PDFs from `documents/`. See `documents/README.md` for which file is which.
